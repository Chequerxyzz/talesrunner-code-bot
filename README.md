# บอทจดโค้ด TalesRunner จากไลฟ์ YouTube → Discord

บอทเฝ้าช่อง https://www.youtube.com/@thehof.talesrunner ให้ พอมีไลฟ์ บอทจะจับภาพจอทุก 15 วินาที
อ่านโค้ดบนจอ (เช่น `COMB8N1Q3M7T`) แล้วส่งเข้า Discord พร้อมเวลา ลิงก์ไปช่วงนั้นของไลฟ์ และรูปหน้าจอไว้เช็ก

- 🔴 พอไลฟ์เริ่ม บอทแจ้งว่า "เริ่มไลฟ์แล้ว"
- 🎁 พอเจอโค้ดใหม่ บอทส่งทันที (ช้ากว่าบนจอประมาณ 30 วินาที – 1 นาที)
- 📋 พอไลฟ์จบ บอทสรุปโค้ดทั้งหมดของไลฟ์นั้น
- 🔁 ทุกคืนตอนตี 2 บอทสแกนคลิปย้อนหลังซ้ำ ถ้ามีโค้ดตกหล่นจะส่งตามให้

ทั้งหมดรันฟรีบน GitHub ไม่ต้องเปิดคอมทิ้งไว้

---

## วิธีติดตั้ง (ทำครั้งเดียว ประมาณ 15 นาที)

### ขั้นที่ 1: สมัคร GitHub
ไปที่ https://github.com/signup แล้วสมัครบัญชีฟรี

### ขั้นที่ 2: สร้างที่เก็บโค้ด (repository)
1. กดปุ่ม **+** มุมขวาบน → **New repository**
2. ช่อง Repository name ใส่ `talesrunner-code-bot`
3. เลือก **Public** ⚠️ สำคัญ: แบบ Public ใช้ฟรีไม่จำกัด ส่วน Private มีโควตาจำกัด บอทใช้ไม่พอ
   (คนอื่นจะเห็นโค้ดโปรแกรม แต่ลิงก์ Discord ของคุณถูกซ่อนไว้ในขั้นที่ 4 ไม่มีใครเห็น)
4. กด **Create repository**

### ขั้นที่ 3: อัปโหลดไฟล์
1. ในหน้า repository ที่เพิ่งสร้าง กดลิงก์ **uploading an existing file**
2. เปิดโฟลเดอร์ `talesrunner-code-bot` ในคอม แล้ว**ลากทุกอย่างข้างใน**ไปวาง
   ต้องมีครบ: โฟลเดอร์ `.github` และ `state`, ไฟล์ `watcher.py`, `requirements.txt`, `README.md`, `.gitignore`
3. กดปุ่ม **Commit changes** สีเขียวด้านล่าง

### ขั้นที่ 4: สร้าง Webhook ใน Discord แล้วใส่เป็นค่าลับ
Webhook คือ "ลิงก์ลับ" ที่ทำให้บอทส่งข้อความเข้าห้อง Discord ได้

**4.1 สร้าง Webhook** (ต้องเป็นเจ้าของหรือแอดมินเซิร์ฟเวอร์ ถ้าไม่มีเซิร์ฟเวอร์ สร้างเซิร์ฟเวอร์ส่วนตัวใหม่ได้ฟรี)
1. ใน Discord ชี้เมาส์ที่ห้องที่จะให้บอทส่งโค้ด (เช่น `#โค้ดเกม`) แล้วกดรูป **⚙️ ฟันเฟือง** ข้างชื่อห้อง
2. เมนูซ้ายเลือก **Integrations (การเชื่อมต่อ)** → **Webhooks** → **New Webhook**
3. ตั้งชื่อ เช่น `TR Code Bot` → กด **Copy Webhook URL**
   ⚠️ ห้ามส่งลิงก์นี้ให้ใคร ใครมีลิงก์ก็ส่งข้อความเข้าห้องนี้ได้

**4.2 ใส่ลิงก์เป็นค่าลับใน GitHub**
1. กลับไปที่หน้า repository ใน GitHub → แท็บ **Settings** (ด้านบนขวา)
2. เมนูซ้าย **Secrets and variables** → **Actions** → ปุ่ม **New repository secret**
3. ช่อง Name ใส่ `DISCORD_WEBHOOK_URL` (พิมพ์ให้ตรงทุกตัว)
4. ช่อง Secret วางลิงก์ที่ก๊อปมา → กด **Add secret**

### ขั้นที่ 5: ทดสอบกับไลฟ์เก่า
1. แท็บ **Actions** (ถ้ามีปุ่มสีเขียวให้เปิดใช้ Actions ให้กดก่อน)
2. เมนูซ้ายเลือก **talesrunner-bot** → ปุ่ม **Run workflow** ด้านขวา
3. ช่อง mode เลือก **test** ลิงก์ไลฟ์เก่าใส่ไว้ให้แล้ว ติ๊ก **ส่งโค้ดที่เจอเข้า Discord ด้วย** → กด **Run workflow**
4. รอประมาณ 20–40 นาที (บอทดูคลิปทั้งคลิป) โค้ดจะเด้งเข้า Discord พร้อมป้าย 🧪 ทดสอบ
   กดดูรายละเอียดได้ที่รายการที่รัน → **test** → **Scan** ท้าย log จะสรุปว่าเจอโค้ดอะไรบ้าง

### ขั้นที่ 6: เสร็จแล้ว 🎉
ไม่ต้องทำอะไรเพิ่ม **talesrunner-bot** จะรันเองทุก 30 นาที และเฝ้าไลฟ์ช่วง 13:30–00:45 น. ทุกวัน
(ในช่วงนี้เช็กว่ามีไลฟ์ไหมทุก 1 นาที) ไลฟ์นอกช่วงเวลานี้ บอทก็ยังตรวจเจอ แต่อาจช้าไปถึง 30 นาที

ถ้าต้องการสั่งให้บอทเริ่มดูไลฟ์ทันที: Actions → **talesrunner-bot** → **Run workflow** → mode เลือก **watch**

## ปัญหาที่อาจเจอ

**ถ้า YouTube บล็อก (Discord เด้งว่า "⚠️ บอทเข้า YouTube ไม่ได้")**
YouTube บล็อกเซิร์ฟเวอร์ของ GitHub ถ้าเด้งครั้งเดียวแล้วตามด้วย ✅ ไม่ต้องทำอะไร ถ้าเด้งบ่อย แก้ได้ 2 ทาง
1. **ใส่คุกกี้ YouTube:** ใช้บัญชี Google สำรอง ไม่ใช่บัญชีหลัก เพราะ YouTube อาจระงับบัญชีที่ถูกใช้แบบนี้
   - เปิดหน้าต่างไม่ระบุตัวตน (Incognito) แล้วล็อกอิน YouTube
   - ในแท็บเดียวกันเปิด `youtube.com/robots.txt` แล้วใช้ส่วนเสริม "Get cookies.txt LOCALLY" export เป็นไฟล์ `cookies.txt`
   - ปิดหน้าต่างไม่ระบุตัวตนทันที (ถ้าใช้ต่อ คุกกี้จะหมดอายุเร็ว)
   - สร้าง secret ชื่อ `YT_COOKIES` แล้ววางเนื้อหาทั้งหมดในไฟล์ลงไป
   - ไม่ต้องเปลี่ยนเป็นรอบ เปลี่ยนเฉพาะตอนที่กลับมาเจอ "Sign in to confirm" บ่อยๆ
2. **รันบนคอมตัวเอง:** ดูหัวข้อท้ายไฟล์นี้

**Discord เด้งว่า "⚠️ ดึงภาพไลฟ์ไม่ได้มาหลายนาทีแล้ว"**
ส่วนใหญ่เกิดจาก YouTube ตัดสัญญาณหรือส่งวิดีโอช่วงที่เสียมา บอทจะลองใหม่เอง (สลับไปใช้ภาพ 720p ให้ด้วย)
ถ้าเด้งแค่นานๆ ครั้ง แล้วตามด้วย ✅ ไม่ต้องทำอะไร ถ้าเด้งค้างนาน ให้ส่งข้อความ error ในกล่องมาให้ผมดู

**บอทหยุดรันเอง**
GitHub จะหยุดงานตั้งเวลาอัตโนมัติ ถ้า repository ไม่มีความเคลื่อนไหวเลย 60 วัน
ปกติบอทบันทึกโค้ดใหม่ลง repo อยู่เรื่อยๆ จึงไม่ค่อยเกิด ถ้าเกิดขึ้น ให้เข้าแท็บ Actions → talesrunner-bot → กด **Enable workflow**

**โค้ดที่บอทส่งมาผิดบางตัว**
ดูจากรูปหน้าจอที่แนบมากับทุกโค้ด แล้วแจ้งผมได้ ผมจะปรับการอ่านให้

## การตั้งค่า (ไม่จำเป็นต้องแก้)
แก้ได้ที่ด้านบนของ `watcher.py` หรือใส่เป็น env ในไฟล์ workflow
- `FRAME_INTERVAL` จับภาพทุกกี่วินาที (ค่าเริ่มต้น 15)
- `CODE_THRESHOLD` คะแนนที่โค้ดต้องสะสมก่อนส่ง (ค่าเริ่มต้น 4 = อ่านได้ชัด 2 ภาพ เพื่อกันอ่านผิด)
  นอกจากนี้ บอทจะส่งเฉพาะโค้ดที่เคยอ่านได้มั่นใจอย่างน้อย 1 ครั้งเสมอ
- `OCR_MIN_SCORE` ความมั่นใจของการอ่านที่นับว่า "ชัด" (ค่าเริ่มต้น 0.85)
- `LIVE_CHECK` ในช่วงเฝ้าไลฟ์ เช็กว่ามีไลฟ์ไหมทุกกี่วินาที (ค่าเริ่มต้น 60)
- `WINDOW_START` / `WINDOW_END` ช่วงเวลาเฝ้าไลฟ์ (ค่าเริ่มต้น 13:30 / 00:45)

## รันบนคอมตัวเอง (ทางเลือกสำรอง)
ติดตั้ง Python 3.11 ก่อน แล้วเปิด PowerShell ในโฟลเดอร์นี้
```powershell
pip install -r requirements.txt
$env:DISCORD_WEBHOOK_URL = "ลิงก์webhook"
python watcher.py watch --max-minutes 720
```
